# Horizontal system logos

Source: https://gitlab.com/es-de/themes/system-logos

Revision: `6344e492f2e164785640320603d7cbc9c303856c`

The ES-DE system logo collection is credited in the upstream ES-DE theming documentation:
https://gitlab.com/es-de/emulationstation-de/-/blob/master/THEMES.md#logos

Colour SVGs from `system-logo-color` were rendered to transparent PNGs at 640 pixels wide.
Compact name logos are also included for complete catalogue coverage. Original
proportions are retained; Orbit trims transparent borders and separated stacked
emblems when displaying them. Filename aliases: `3ds` uses
`n3ds.svg`, and `astrocde` uses `astrocade.svg`.

These logos appear by default and also provide local alternatives when a user's
stacked logo cannot be reduced to its name without cutting through the lettering.
Custom logo assignments take priority. The user's saved originals are not changed.
Logos and trademarks belong to their respective owners.

Orbit's Epic Games entry uses a plain white name wordmark. Its Adobe Flash entry
adds the name beside the original Flash icon. Those labels are rendered using
Segoe UI; no font files are bundled.
